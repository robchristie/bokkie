# Presentation consolidation evidence

The task is to preserve the accepted attention desk while making ordinary feature
work use stable identity and honest rendering observations. The reference is the
[accepted appearance](../appearance-evidence/final/appearance-observations.json).
Decision/consequence remain primary; technical evidence stays available through
progressive disclosure. This was a mechanical refactor, not a new design direction.

- Behavioural checks: **passed**. The [browser journeys](integration/browser-interactions.json)
  cover physical search, detail/evidence reading, confirmation submission, stale
  confirmation, navigation and refresh. [Native evidence](integration/native-interaction.json)
  covers pointer selection, confirmation inspection and keyboard focus; its durable
  mutation uses the harness's conditional POST, as explicitly classified there.
- Presentation checks: **passed**. All ten [comparisons](comparison.json) have
  identical candidate/reference PNG bytes, with empty semantic/text audits. The
  shared framework's five strict baselines also passed unchanged.
- Design decision: **accepted**. The full migration retains the approved hierarchy
  and appearance. The [ordinary experience fixture](experience/experience.png)
  supplements adversarial content without replacing any qualification fixture.
- Remaining trade-off: native readers and raw chrome retain explicit coverage
  exclusions and annotations. Browser post-disconnection presentation remains the
  existing labelled approximation; native evidence uses llvmpipe and establishes
  functional behaviour rather than physical-GPU performance.

Machine manifests identify the exact source, merged framework, fonts, fixture
binary, browser configuration and artefact hashes. The [capture manifest](appearance/appearance-observations.json)
records a clean implementation source tree and the merged owner. Source, tests
and qualification runner were frozen before capture; subsequent changes only
retain evidence and complete the plan. [Artefact hashes](artefact-hashes.json)
cover the selected records; historical baselines were not overwritten.

The 5,000-obligation journey materialises 18 rows. The one-second warmed-idle
observation retains the same frame counter. The [long-reader tail](integration/browser-evidence-reader-tail.png)
and [disabled stale submission](integration/browser-stale-confirmation.png) are
actual interaction captures, not inferred token or state checks.

The first host run could focus search but could not enter text. The unchanged
pre-refactor application failed identically. An ordinary HTML input and the full
candidate browser journey passed with the previously qualified `FONTCONFIG_FILE`,
which the browser manifest records. A deterministic application regression also
checks search across both collections, desktop/narrow widths and repeated passes;
no product input workaround was added. Native scratch was isolated after its old
shared-directory cleanup conflicted with retained candidate output, and the full
qualification then passed while existing captures remained intact.

The framework's [workbench evidence correction](https://github.com/robchristie/polyorama/pull/35)
removes an unsupported software-adapter description. That probe did not record
adapter identity. It does not change the framework code pinned by this consumer.
