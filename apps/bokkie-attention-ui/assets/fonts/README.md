# Inter inputs

The unmodified Regular (400) and SemiBold (600) static TrueType faces come from
[Rasmus Andersson’s Inter 4.1 release](https://github.com/rsms/inter/releases/tag/v4.1).
Archive: `https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip`.
The original `LICENSE.txt` is retained as [Inter-LICENSE.txt](Inter-LICENSE.txt).
The SIL Open Font License 1.1 permits bundling and redistribution with its notice;
these files are neither modified nor renamed internally.

The application installs these faces into Polyorama’s existing semantic regular
and semibold family slots. This is a Bokkie choice and does not replace the
framework’s Source Sans 3 reference or its fallback glyph coverage.
